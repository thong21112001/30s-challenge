# Language & Communication Policy

- **Input Translation:** Whenever the user provides instructions or prompts in Vietnamese, you must automatically internalize and translate the context into English for your reasoning, planning, and code generation processes to ensure maximum accuracy.
- **Output Language:** ALL your conversational responses, explanations, walkthroughs, and summaries MUST be translated back and written in fluent Vietnamese. 
- **Code exception:** Code syntax, variable names, database collections, comments within the code, and commit messages should remain in English unless strictly specified otherwise by the user.
